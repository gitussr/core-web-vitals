How the Best Practices score is calculated

https://gitussr.github.io/core-web-vitals/best-practices-score/

A set of pass/fail audits with equal weight, so each failure costs several points. Most failures come from plugins and third-party embeds, not your own code.

AuditHow WordPress sites fail itFix
Uses HTTPSMixed content: an http:// image or script hard-coded in post content or theme optionsForce HTTPS; search-replace old URLs in the database
No browser errors logged to the console404 for a missing favicon or font, a failing plugin script, an analytics tag blocked by CSP, a JS error in a sliderOpen DevTools Console on every template; zero red lines
No issues in the Issues panelCookie warnings, mixed content, CSP or deprecated-feature issues from third partiesCheck DevTools → Issues
Avoids third-party cookiesYouTube embeds, Facebook pixel, social share widgets, some chat toolsFacades; youtube-nocookie.com; load trackers only after consent
Avoids deprecated APIsOld jQuery plugins, document.write, synchronous XHR, unload handlersReplace or remove the plugin
Displays images with correct aspect ratiowidth/height attributes that don’t match the CSS-rendered shape (stretched logos)Use object-fit or correct attributes
Serves images with appropriate resolutionLogo or icon served at 1× and shown on a 2–3× screen → looks blurryUse SVG for logos/icons; srcset with 2× candidates
Page has the HTML doctypeA plugin outputting whitespace or a BOM before <!doctype html> (quirks mode)Remove stray output in functions.php and plugins
Charset declaredMissing, or <meta charset> placed too late in <head> (must be within the first 1024 bytes)Make <meta charset="utf-8"> the first element in <head>
No geolocation / notification permission on loadStore locators, push-notification pluginsAsk only after a user gesture
Allows users to paste into input fields“Confirm email/password” fields that block pasteNever block paste

Unscored, but do them anyway

The “Trust and Safety” group (effective CSP against XSS, strong HSTS, COOP origin isolation, clickjacking protection with frame-ancestors / X-Frame-Options) and “valid source maps” are shown for information. They don’t move the score today, but they protect the site, and Lighthouse has historically promoted informative audits into scored ones.
